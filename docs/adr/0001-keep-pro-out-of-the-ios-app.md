# Keep Pro out of the iOS app

Pro, the Stripe subscription behind voice input, AI enhancement, and text and
image import, is a reference implementation of a paid tier in a portfolio
project. Nobody is expected to buy it. Apple rejects apps that link or point to
buying digital goods outside the App Store (guidelines 3.1.1 and 3.1.3), so
showing Pro in the iOS app would only invite a rejection for a feature with no
customers. The iOS app therefore shows none of it: no upgrade page, no Pro
button or nudge, no subscription management, and no copy about Pro. A free user
sees those features absent rather than locked, and a Pro user keeps them. The
web keeps the whole subscription flow as the demonstration it is.
